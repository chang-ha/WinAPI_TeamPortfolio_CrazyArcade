# Crazy Arcade 모작
해당 팀프로젝트는 WindowAPI 공부 목적으로 만든 프로젝트입니다.  

    모작 게임 : Crazy Arcade
    참여 인원 : 5명
    개발 기간 : 약 1개월

## 실행전 주의사항
1. #### `CrazyArcade` 프로젝트를 시작 프로젝트로 설정해 주세요.

*** 
### 팀원구성

|구분|이름|역할|
|:---:|:---:|:---:|
|1|우창하|보스|
|2|김서영|캐릭터 및 몬스터|
|3|김태욱|캐릭터|
|4|김태훈|UI|
|5|조대규|타일맵, 아이템|
***

### 조작키

|가상키|역할|
|:---:|:---:|
|W,A,S,D|Player1 상,하,좌,우 이동키|
|Space|Player1 물폭탄 설치|
|방향키|Player2 상,하,좌,우 이동키|
|R_Shift|Player2 물폭탄 설치|
|Ctrl|아이템 사용|
***

### 디버그 키

|가상키|역할|
|:---:|:---:|
|F1|Title로 이동|
|F2|Test맵으로 이동|
|F3|맵 에디터로 이동|
|F4|대기방으로 이동|
|F5|스테이지1로 이동|
|F6|스테이지2로 이동|
|F7|스테이지3로 이동|
|6|스테이지 승리 판정|
|H|Collision On/Off|

### 스테이지 디버그 키
|가상키|역할|
|:---:|:---:|
|R|모든 Player 부활|
|F9|모든 몬스터 사망|
|F|모든 몬스터 얼리기|
|I|모든 아이템 시각화|
|1|보스 패턴 1|
|2|보스 패턴 2|
|3|보스 패턴 3|
|4|보스 패턴 4|
|5|보스 이동|
|7|보스 무적 On/Off|
